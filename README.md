# django-pip-with-nested-manage-example

Репозиторий для демонстрации деплоя проекта на Python с фреймворком Django и пакетным менеджером pip с файлом manage.py не в корне проекта

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/manage.py runserver
```
